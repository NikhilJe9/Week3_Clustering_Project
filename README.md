# Week 3: Unsupervised Learning and Clustering Analysis

Dataset: Palmer Penguins from the public seaborn-data repository.

## Files
- `notebooks/Week3_Unsupervised_Clustering.ipynb`: runnable clustering analysis
- `reports/Week3_Clustering_Report_DRAFT.docx`: report draft
- `figures/`: plots generated after notebook execution

## Methods
Median imputation, standard scaling, K-Means with elbow/silhouette diagnostics, PCA visualization, cluster profiles, and agglomerative clustering comparison.

## Run
Upload the notebook to Google Colab and choose Runtime → Run all. Review actual outputs, download generated plots/CSVs, insert them into the report, replace placeholders and verify everything before submission.

Dataset source: https://github.com/mwaskom/seaborn-data/blob/master/penguins.csv
